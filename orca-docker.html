ORCA Docker Workbench

Kirim input ORCA dari Input Builder ke Docker lokal, agen MacBook, atau HPC (Slurm); pantau log langsung; lalu kirim hasil ke Results Analyzer.

Mode DEMO (simulasi) belum diuji
Mode DEMO aktif. Tidak ada backend yang dihubungi; job disimulasikan di browser dengan keluaran ORCA contoh (bukan hasil perhitungan nyata). Matikan opsi demo untuk memakai backend sungguhan.

API key disimpan di localStorage browser ini saja. Jangan dipakai di komputer bersama.

    Langkah cepat

    1. Tab Koneksi: isi URL backend (mis. http://127.0.0.1:8000), API key, pilih jalur, Test koneksi.
    2. Buat input di Input Builder → tombol kirim ke Docker, atau tempel/unggah .inp di tab Submit.
    3. Periksa peringatan (nprocs, maxcore, berkas koordinat), lalu Submit.
    4. Pantau di Monitor; saat done, buka Hasil → analisis → Kirim ke Results Analyzer.

    Jalur

    • local_docker: backend FastAPI (backend/) menjalankan docker run di mesinnya.
    • local_agent: job diantrekan di backend; local-agent/agent.py poll di MacBook mengambilnya. Atau arahkan URL langsung ke http://127.0.0.1:8765 (agent serve) dengan jalur local_docker.
    • slurm_brin: backend mengirim sbatch via SSH. Partisi/modul diisi di .env backend sesuai dokumentasi cluster Anda.

    ORCA tidak disertakan

    Anda perlu lisensi/unduhan ORCA sendiri dan image Docker pribadi. Lihat local-agent/README.md.

    Keamanan

    • Backend mengeksekusi input yang Anda kirim. Selalu set API_KEY, batasi CORS_ORIGINS ke origin Pages Anda.
    • Halaman HTTPS hanya bisa memanggil backend HTTPS, kecuali localhost/127.0.0.1 (Chrome/Firefox). Safari memblokir http://localhost dari halaman HTTPS.
    • API key tersimpan di localStorage; jangan simpan di komputer umum.

    Pemecahan masalah

    "Failed to fetch"
    Backend mati, URL salah, CORS tidak mengizinkan origin ini, atau mixed content (HTTPS→HTTP). Cek konsol browser.
    401
    API key salah.
    503 backend tidak tersedia
    Docker Desktop belum jalan / Slurm belum dikonfigurasi (lihat Test koneksi).
    Job "failed" tanpa .out
    Image tidak ada, atau orca tidak di PATH image. Coba docker run --rm IMAGE which orca.
    ORCA paralel gagal
    Perlu path absolut ($(which orca) — sudah dipakai), %pal nprocs sama dengan nprocs, dan MPI terpasang di image.
    Analyzer tidak menerima hasil besar
    Hasil sangat besar melebihi kuota localStorage; halaman memakai sessionStorage/IndexedDB, atau unduh .out dan unggah manual.
