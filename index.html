Kimia komputasi · DFT · ORCA · Gaussian

Dari persamaan Schrödinger sampai spektrum serapan — dalam satu alur kerja.

Belajar DFT lewat visual interaktif, bangun molekul 3D, siapkan input ORCA/Gaussian, jalankan di Docker atau HPC, lalu analisis hasilnya: geometri, frekuensi, orbital, parameter elektrokimia, dan TDDFT. Semua alat berjalan di browser Anda.

1 Belajar→2 Bangun molekul→3 Input ORCA/Gaussian→4 Jalankan (Docker/HPC)→5 Analisis
Modul 1

Kuliah interaktif DFT

Mengapa simulasi penting (dengan rujukan paper), Schrödinger, kerumitan banyak-elektron, teorema Hohenberg–Kohn, siklus SCF, basis set, tangga Jacob, biaya komputasi, PES & frekuensi, TDDFT, dan kuis.

Mulai belajar → Alat 2

Molecular Builder

SMILES / nama / pustaka → 2D, deskriptor, seri substituen, lalu 3D + pre-optimize (konformer, force field) dan ekspor XYZ/SDF.

Bangun molekul → Alat 3

Input Builder ORCA & Gaussian

Opt, Freq, TDDFT, scan, TS, solvasi, SCF, keluaran molden/fchk, batch, plus skrip SLURM & Docker. Terhubung langsung dari Molecular Builder.

Siapkan input → Alat 4

Results Analyzer

Unggah .out/.log (+ molden/fchk): geometri teroptimasi, cek imaginary frequency, ikatan/sudut/dihedral/planaritas, HOMO/LUMO 3D, level energi, IP/EA/η/ω, spektrum UV-Vis, tabel TDDFT, panel DSSC.

Analisis hasil → Alat 5

ORCA Docker Workbench

Kirim job ke Docker lokal, agen di MacBook, atau SLURM HPC BRIN; pantau log & progres SCF/optimasi; kirim hasil ke Analyzer. Mode demo tersedia tanpa backend.

Buka workbench →
Catatan

Privasi & lisensi

Berkas Anda diproses lokal di browser (tidak diunggah) kecuali Anda sendiri mengaktifkan backend. ORCA/Gaussian berlisensi dan tidak disertakan; Anda memakai instalasi/lisensi sendiri.

Contoh cepat

  1. Buka Molecular Builder → pilih “Azobenzena” → Generate 3D + pre-optimize → Lanjut → ORCA input.
  2. Atur preset Optimasi + frekuensi, unduh .inp, jalankan di ORCA Anda (atau Docker/HPC).
  3. Unggah .out (+ .molden) ke Results Analyzer; atau coba tombol Contoh di sana.
