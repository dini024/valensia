Molecular Builder

SMILES → 2D → 3D + pre-optimasi (RDKit.js + force field ringan), lalu lanjut ke Input Builder ORCA / Gaussian. Semua dijalankan di browser; backend RDKit penuh (ETKDG + MMFF94) bersifat opsional.

Pustaka molekul

Lainnya: PubChem · ChEMBL · ZINC (tempel SMILES hasilnya di bawah)

SMILES → molekul

Desain seri substituen

Core SMILES harus memuat tepat satu titik sambung [*]. Substituen ditulis sebagai SMILES yang dimulai dari atom penyambung (mis. OC, C#N, C(=O)O). Pisahkan dengan spasi, koma, atau baris baru.

Struktur 2D

Belum ada struktur.
Deskriptor ini adalah deskriptor struktural (RDKit), bukan hasil DFT.

Struktur 3D

Tekan “Generate 3D + pre-optimize”.

Lanjut ke input ORCA

Input Builder memuat molekul ini otomatis, lalu Anda memilih job (opt/freq/TDDFT…), fungsional, basis set, dan pelarut. Hasil dapat dikirim ke ORCA Docker Workbench.

Lanjut ke input Gaussian

Input Builder memuat molekul ini otomatis dan membuka tab Gaussian (route section, %chk, TD-DFT, pelarut, dll.).

Dibangun dengan RDKit.js (SMILES, depiksi, deskriptor), force field ringan di browser (3D + pre-optimasi), dan 3Dmol.js. Struktur hasil pre-optimasi adalah titik awal — selalu optimasi ulang dengan DFT dan periksa geometri sebelum perhitungan ilmiah.
